# Sonsuz Bürokrasi Simülatörü

Bu proje, insanlığın en büyük başarısı olan bürokrasiyi, dijital çağa taşımak için tasarlanmıştır. Artık sınırsız evrak, sonsuz bekleme ve bitmeyen imza zincirleri sizin elinizde!

## Nasıl Çalışır?

```bash
python burokrasi.py
```

Ve izleyin... İmza bekleniyor. Eksik belge var. Şef izinde. Çay molası başladı. Sistem çöktü. Yine mi?

Bu simülatör o kadar gerçekçi ki, çalıştırdıktan sonra gerçek hayatta da form doldurmak isteyeceksiniz. Veya istemeyeceksiniz. Belki de her ikisi.

### Özellikler
- Sonsuz loop (asla bitmez, tıpkı gerçek bürokrasi gibi)
- Rastgele gecikmeler
- Abartılı Türkçe resmi dil
- Çay demleme protokolü entegrasyonu (gizli)
